# Character メソッド - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない可能性があります。]

- **説明**
    - [**Characters**](/ja-jp/windows/desktop/lwef/the-characters-object) コレクション内の [**Character**](/ja-jp/windows/desktop/lwef/the-characters-object) オブジェクトを返します。
- **構文の**
    - エージェント \*\* です。Characters.Character "***CharacterID***"\*\*

## 備考

このメソッドを使用して、[**Character**](/ja-jp/windows/desktop/lwef/the-characters-object) オブジェクトのメソッドとプロパティにアクセスできます。

手記

コレクションをサポートしていない一部のプログラミング言語では、このメソッドが必要になる場合があります。 VBScript または Visual Basic では必要ありません。 Character**[メソッド](/ja-jp/windows/desktop/lwef/the-characters-object)**指定する方法の詳細については、「Character オブジェクト メソッド」を参照してください。
