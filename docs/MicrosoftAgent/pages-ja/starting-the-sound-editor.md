# サウンド エディターの起動 - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない可能性があります。]

Microsoft 言語情報サウンド編集ツールを実行するには、**[スタート]** メニューから選択するか、サウンド エディターのアイコンをダブルクリックします。 サウンド エディターのウィンドウが開き、メニューが表示され、頻繁に使用されるコマンド用のツール バー、エディターがサウンド ファイルの処理に使用する単語を入力するためのテキスト ボックス、オーディオおよび言語データを表示および編集するための表示領域が表示されます。

![Microsoft 言語情報サウンド編集ツールの開始ページを示すスクリーンショット。](images/f1listliq.gif)

サウンド エディターが起動したら、新しいサウンド ファイルの録音を開始するか、既存のサウンド ファイルを読み込むことができます。
