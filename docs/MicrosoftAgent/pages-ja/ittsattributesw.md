# ITTSAttributesW - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない可能性があります。]

エンジンは、[**PitchSet**](https://www.bing.com/search?q=**PitchSet**)、[**PitchGet**](https://www.bing.com/search?q=**PitchGet**)、[**SpeedSet**](https://www.bing.com/search?q=**SpeedSet**)、および SpeedGet**[メソッドを使用して、ピッチ属性と速度属性](https://www.bing.com/search?q=**SpeedGet**)**サポートする必要があります。
