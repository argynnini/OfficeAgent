# Wordバルーン - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない場合があります。]

音声出力に加えて、Microsoft エージェント インターフェイスでは、漫画スタイルのワード バルーンのテキスト出力形式のテキスト キャプションがサポートされています。 吹き出しの中に単語が読み上げられると表示されます。 吹き出しは、音声出力が完了すると非表示になります。 [文字オプションの詳細設定] ウィンドウには、バルーンの表示を無効にするオプションと、その外観に関連するコントロール属性が表示されます。
