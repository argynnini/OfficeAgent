# Microsoft エージェントのトラブルシューティング - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない場合があります。]

コンピューターで Microsoft エージェントを実行するのが難しい場合は、次の症状の一覧を参照し、問題を特定して解決するための推奨される手順を試してください。

- [インストールとページの読み込みに関する問題](installation-and-page-loading-problems)
- [出力の問題](output-problems)
- [音声入力の問題](speech-input-problems)
