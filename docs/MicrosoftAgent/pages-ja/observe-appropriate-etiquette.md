# 適切なエチケットを観察する - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない可能性があります。]

すべての人間は社会的エチケットのルールを学びます。 さらに、これらの規則にどの程度準拠しているかに基づいて、他のユーザーを判断します。 インターフェイスに文字が存在すると、エチケットのルールがデザインに直接適用されます。

私たちは相互作用の相互性を期待しており、それが起こらないとき、私たちはその行動を無能または不快と見なす傾向があります。 新しい状況や正式な状況では、通常、丁寧さが期待されます。 リレーションシップが確立された後にのみ、知識によって、より正式な対話が可能になります。 だから、疑わしいときは、丁寧にしてください。

たとえば、ソーシャルインタラクションを開始および終了するための適切なプロトコルを考えてみましょう。 新しい社会的文脈に従事するとき、私たちは一般的にお互いに挨拶し、出発する前に出発する意思を示します。 このモデルは、文字の相互作用に直接適用できます。適切な指示なしに文字が現れたり消えたりしないようにしてください。

丁寧さの一部は、私たちがどのように対応するかです。 適切な応答が期待されます。 たとえば、"What day is it?" (何日ですか) と尋ねると、応答が "10 リンゴ" になるとは思われません。ただし、精度と関連性は十分ではありません。コンテキストを決定する必要がある場合もあります。 正確な応答は、"月曜日" または "8 月 25 日^番目の^" です。同様に、応答の文言は正確ですが、イントネーション、表情、その他の言葉以外の行動に応じて、不快なままです。

さらに、話しながら互いに話し合います。私たちは人と向き合い、何かに直接注意を向けるだけです。 何らかの目的を持たずに自分の背中を戻すことは、無関心を意味し、一般的に無礼であると考えられています。

また、丁寧さは、他のユーザーに対する対応や認識方法にも影響します。 たとえば、ソーシャルリサーチは、他の人から尋ねられたときよりも、他の人の評価について正直になる可能性が高いと示しています。 同様に、肯定的な自己評価よりも容易に他の人の肯定的な評価を受け入れます。 一般的に、最も変化の少ない動作は無意味と見なされます。 したがって、意図的に非礼な性格スタイルを促進しようとする場合を除き、キャラクターが独自のパフォーマンスを補完することは避けてください。

また、社会的エチケットに文化的影響を考慮してください。 これは、キャラクターの装い、ジェスチャー、または単語の選択に適用される場合があります。 丁寧な行動は文化によって異なるかもしれませんが、丁寧さの概念は異なる文化です。
