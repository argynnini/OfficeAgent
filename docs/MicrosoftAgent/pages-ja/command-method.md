# Command メソッド - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない可能性があります。]

- **説明**
    - [**Commands**](/ja-jp/windows/desktop/lwef/the-commands-collection-object) コレクション内の [**Command**](/ja-jp/windows/desktop/lwef/the-command-object) オブジェクトを返します。
- **構文の**
    - エージェント \*\* です。characters ("***CharacterID***")。Commands.Command\*\* "*Name*"

## 備考

このメソッドを使用すると、[**Command**](/ja-jp/windows/desktop/lwef/the-command-object) オブジェクトのプロパティにアクセスできます。

手記

このメソッドは、一部のプログラミング言語で必要になる場合があります。 VBScript または Visual Basic では必要ありません。 Command **メソッド** 指定する方法の詳細については、「Command オブジェクトのプロパティ」を参照してください。
