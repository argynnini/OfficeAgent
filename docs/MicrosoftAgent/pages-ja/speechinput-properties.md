# SpeechInput プロパティ - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない可能性があります。]

音声認識エンジンがインストールされ、有効になっている場合、次のプロパティにアクセスすると、音声認識エンジンが起動します。

- [**Enabled**](enabled-property-sio)
- [**HotKey**](hotkey-property)
- [**ListeningTip**](listeningtip-property)
