# 出力ページ - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない場合があります。]

このページには、文字出力を制御するプロパティが含まれています。 たとえば、ユーザーは、バルーンという単語に出力を表示するかどうか、バルーン出力の表示方法の決定、音声としての音声出力の再生、キャラクターのサウンド 効果の再生、再起動プロンプトの表示、読み上げ速度の調整を行うことができます。
