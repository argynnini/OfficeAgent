# 既存のサウンド ファイルを読み込む - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンのWindowsでは使用できない場合があります。

[**ファイル] メニュー**またはツール バーから **[開**く] コマンドを選択して、既存のWindowsサウンド ファイル (.wav) または言語拡張サウンド ファイル (.lwv) を読み込むこともできます。 [ **開く** ] ダイアログ ボックスが表示されます。 ファイルを選択し、[ **開く** ] をクリックしてエディターにファイルを読み込みます。
