# エージェント コントロール - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない場合があります。]

エージェント コントロールを参照すると、Microsoft エージェントでサポートされているイベントやその他のほとんどのオブジェクトにアクセスできます。 エージェント コントロールは、独自のプロパティ のセットも直接公開します。

- [エージェント制御メソッド](agent-control-methods)
- [エージェント コントロールのプロパティ](agent-control-properties)
- [エージェント コントロール イベント](agent-control-events)
