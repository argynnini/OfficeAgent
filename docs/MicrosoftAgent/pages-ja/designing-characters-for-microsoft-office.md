# Microsoft Office の文字のデザイン - Win32 apps | Microsoft Learn

[Microsoft エージェントは Windows 7 の時点で非推奨となり、以降のバージョンの Windows では使用できない場合があります。]

このドキュメントでは、Microsoft Office 2000 内で使用する Microsoft エージェント文字を設計および開発するのに役立つ情報を提供します (Microsoft エージェントの文字は Microsoft Office 97 では機能しません)。 このドキュメントでは、Microsoft エージェント 文字エディターに関する実用的な知識があり、Microsoft エージェント文字を作成する方法を理解していることを前提としています。 エージェント文字エディターと文字の設計と開発の詳細については、「 [Microsoft エージェント文字エディターの使用」を参照してください](using-the-microsoft-agent-character-editor)。 Microsoft エージェントの文字の作成の詳細については、「Microsoft エージェントの [文字の設計」](designing-characters-for-microsoft-agent)を参照してください。
